# Admin Countdown Menu - User Guide

## 📍 Akses Menu Countdown

### Cara Mengakses:
1. **Login sebagai Admin**
2. **Buka Sidebar** (klik ikon hamburger di kiri atas)
3. **Pilih Menu "Lantik"** (dengan ikon Clock 🕐)

## 🎯 Fitur Menu Countdown

### 1. **Create Countdown**
- Klik tombol "Create New Countdown"
- Isi form:
  - **Title**: Judul countdown (contoh: "HARI JADI", "AFFAN")
  - **Description**: Deskripsi countdown (contoh: "HAHAHAH KETIPU")
  - **Target Time**: Waktu target countdown
  - **Show Only Countdown**: ✅ Centang untuk mode countdown only (menyembunyikan konten day)

### 2. **Manage Existing Countdown**
- **Activate/Deactivate**: Toggle countdown on/off
- **Edit**: Ubah title, description, target time
- **Delete**: Hapus countdown
- **Preview**: Lihat status countdown

### 3. **Countdown Modes**

#### Mode Normal:
- Countdown aktif tapi konten day masih tampil
- User melihat: Homepage normal + countdown banner

#### Mode "Show Only Countdown":
- ✅ **Menyembunyikan semua konten day**
- ✅ **Background berubah ke hari-kemenangan.jpg**
- ✅ **Countdown besar di tengah**
- ✅ **Menu dibatasi untuk user biasa**
- ✅ **Admin tetap melihat semua konten**

## 🎨 Tampilan Countdown

### Format: `{jam}:{menit}:{detik}`
- Jika > 24 jam: total jam akan ditampilkan (contoh: 25:30:45)
- Font besar dan monospace
- Tanpa kotak background
- Posisi tengah layar

## 🔐 Admin Privileges

Sebagai admin, Anda memiliki akses khusus:
- ✅ Menu "Lantik" selalu terlihat
- ✅ Dapat melihat konten day meski countdown mode aktif
- ✅ Akses penuh ke semua menu
- ✅ Dapat mengelola countdown kapan saja

## 📱 Responsive Design

Menu dan countdown berfungsi optimal di:
- 📱 Mobile devices
- 💻 Tablet
- 🖥️ Desktop
